MACD指标说明
MACD（Moving Average Convergence Divergence，异同移动平均线）是一个趋势跟踪动量指标，用于显示两个移动平均线之间的关系：

正值（如0.002348, 0.002559, 0.021558）：

表示短期（12日EMA）高于长期（26日EMA）趋势
通常被视为看涨信号
负值（如-0.008625, -0.003938）：

表示短期（12日EMA）低于长期（26日EMA）趋势
通常被视为看跌信号


MACD_EXP = "(EMA($close, 12) - EMA($close, 26))/$close - EMA((EMA($close, 12) - EMA($close, 26))/$close, 9)/$close"

EMA($close, 12)：计算收盘价的12日指数移动平均线
EMA($close, 26)：计算收盘价的26日指数移动平均线

/$close：将EMA的结果除以收盘价，以归一化结果

EMA((EMA($close, 12) - EMA($close, 26))/$close, 9)/$close：计算9日MACD指数平均线的指数移动平均线

与传统MACD的区别
传统的MACD计算方法是：

MACD线 = 12日EMA - 26日EMA
信号线 = MACD线的9日EMA
柱状图 = MACD线 - 信号线
而在Qlib中的这个表达式则是：

标准化MACD线 = (12日EMA - 26日EMA) / 收盘价
标准化信号线 = 标准化MACD线的9日EMA / 收盘价
最终结果 = 标准化MACD线 - 标准化信号线
标准化的目的
这种标准化处理的主要目的是：

消除价格水平的影响：使得不同价格的股票可以进行比较
提高模型训练效果：标准化的数据通常更有利于机器学习模型的训练
增强指标的可解释性：将指标值限制在相对较小的范围内
实际意义
在实际使用中：

正值：表示短期趋势强于长期趋势，可能看涨
负值：表示短期趋势弱于长期趋势，可能看跌
零值交叉：可能的买卖信号点
这种经过标准化的MACD指标更适合用于量化交易策略中，特别是机器学习模型的特征输入。
